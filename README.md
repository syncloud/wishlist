# Wishlist

[Wishlist](https://github.com/cmintey/wishlist) packaged for [Syncloud](https://syncloud.org).

Share wishlists with friends and family, and claim gifts without the owner finding out.

Sign-in uses Syncloud SSO. Members of the `syncloud` group are Wishlist admins.

On first use the admin picks the default group under Admin → Settings → General, so that family members who sign in later join it automatically.
